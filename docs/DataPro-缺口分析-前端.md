## 6. 前端共性基础设施与红线

1. **可复用基建**：统一 `branding.json` + CSS 变量（S-F02）；全局通知组件（U-F11 阶段一）；`HelpView.vue` 静态 FAQ（U-F12/S-F04 共用）；SVG 轻量图表组件（U-F04）。
2. **视觉红线**（`AGENTS.md §4.2-6`）：不用弹窗、不用常驻长文案、去渐变/光晕/彩色阴影、字重≤600、单一强调色、4px 网格。U-F01 引导必须用主区卡片而非 modal。
3. **SSE 兼容**：`data_as_of` / `memory_notes` 是可选字段，老结果不显示即可；不得改既有事件类型与字段名。
4. **前端不是安全防线**：U-F10 管理入口隐藏不作为唯一权限控制，写操作仍走后端 `require_admin` / 权限点（`AGENTS.md §4.1`）。
5. **不要重复造轮子**：U-F03 后端已下发定义摘要；U-F06 已有 `explanation`；U-F08 B13 导出全链路已实现；U-F02 的 F38 是预设回复、不可当个人收藏交付；站外产品页已存在（缺的是链路不是页面）。
