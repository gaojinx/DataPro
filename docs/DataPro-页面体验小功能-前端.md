## 1. 范围与口径

### 1.1 什么叫「小功能」
微交互 / 小细节 / 显示层增强，**一两天可落地、用户下次使用就能感知**。需要新增页面、新增后端表、改 9 节点状态机、动权限模型的属于「缺口」不属于「小功能」。每条均有 `App.vue:行号` 或 `style.css:行号` 证明当前确实缺。

## 5. 前端红线与验收约定

### 5.1 视觉红线（`AGENTS.md §4.2-6`）
- 不用弹窗、不用常驻小字解释功能，一律图标 / 徽标 / `data-tip`（原语在 `style.css:1326-1343`）；
- 去渐变 / 光晕 / 彩色阴影、单一强调色、字重 ≤600、4px 网格；
- X-L01 禁渐变 shimmer、X-C02 禁彩色阴影、X-A01 缩放破坏网格；
- X-L01 / X-C02 新增动画必须纳入 `prefers-reduced-motion`（`style.css:2262-2276`）。

### 5.2 数据语义红线
- X-R03 **只处理 `null/undefined`，`0` 原样显示**，不动后端自检探针与脱敏；
- X-R04 **禁止对字符串做启发式千分位**，会改坏订单号；
- X-R02 / X-R06 用排序状态 + 分页切片生成**视图**，`msg.result.rows` 原数组只读，不污染导出/复制数据源。

### 5.3 验证方式
- 固定流程：`npm run build`（Windows 需先覆盖 `TEMP`/`TMP` 到 `datapro/.tmp`）+ 源码静态检查；本机浏览器自动化不可用（`AGENTS.md §6`），必要时人工打开 `127.0.0.1:5175` 目检；
- 每批实现同批更新 `docs/DataPro-功能清单.md`（含变更登记）与 `AGENTS.md §4.1 前端体验`（§4.2-9 / §8「功能先登记再开发」）。
