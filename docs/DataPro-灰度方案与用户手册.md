# 第一部分：灰度方案

## 1. 灰度节奏

| 批次 | 范围 | 人数 | 观察期 | 准出条件 |
|---|---|---|---|---|
| 内部 | 数据团队自用 | 5~10 | 1 周 | 日常使用无阻断性 bug |
| 灰度 1 | 单个业务部门（试点） | 20~30 | 1 周 | 正确率抽检 ≥90%，周 👎 率 <20% |
| 灰度 2 | 再加 1~2 个部门 | 50~100 | 2 周 | 指标趋势稳定，无安全事件 |
| 全量 | 全公司 | — | — | G5 复盘通过 |

## 2. 灰度保障机制

- **快速回滚**：配置开关一键停服（前端显示维护中），恢复 < 1 分钟
- **反馈闭环**：结果页 👍/👎 必填引导（👎 时选原因：数据不对/口径不对/没听懂/其他）；每周汇总 Top 问题清单
- **人工兜底**：转人工工单 SLA 1 个工作日；灰度群内数据接口人 10 分钟响应
- **每日站会**（灰度期 15 分钟）：昨日指标 + 阻塞问题

## 3. 灰度期每日监控看板

| 指标 | 告警阈值 |
|---|---|
| 日均请求数 / 拒答率 | 拒答率 >40% 触发排查 |
| 可执行率 / 幻觉率 | 低于章程门槛即预警 |
| 👎 率及原因分布 | 👎 率 >25% 暂停灰度扩量 |
| E005/E006 错误率 | >5% 值班响应 |

# 第二部分：用户手册（面向业务用户）

## 1. DataPro 能做什么

- **帮你查数**：用大白话提问，直接返回数据表格
- **帮你答疑**：问字段含义、指标口径（"GMV 是怎么算的？"）
- **帮你盯数**：核心表每日自动体检，异常主动告警（管理员配置）

## 2. 怎么问效果好（黄金公式）

```text
【指标】+【时间范围】+【维度/过滤条件】

❌ "销售额多少"          → 会追问
✅ "上个月华东区的销售额，按周汇总"

❌ "活跃用户"            → 会追问日活还是月活
✅ "最近 30 天的日活趋势"
```

## 3. 支持追问

第一轮没答全，直接接着说：
- "那按渠道拆一下"
- "上周呢"
- "只看退款订单"

## 4. DataPro 不会做什么

| 不会做 | 说明 |
|---|---|
| 修改任何数据 | 只读查询，写操作一律拒绝 |
| 查无权限的数据 | 按你的账号权限返回 |
| 一次返回超大数据 | 超过 1 万行只给摘要，可申请导出（需审批） |
| 下业务结论 | 只呈现数据，结论请结合业务判断 |
| 猜口径 | 口径库没有的指标会明确告诉你"未收录" |

## 5. 结果说明

- 每个结果附有：生成的查询逻辑（一句话）+ AI 做的假设
- **重要决策请人工复核**——AI 可能对口径有理解偏差
- 觉得数据不对请点 👎，会有人跟进

## 6. 遇到问题

1. 结果不对 → 点 👎 选原因
2. 找不到数据 → 联系数据接口人（灰度群）
3. 系统故障 → 联系管理员，报页面上的 trace 编号
