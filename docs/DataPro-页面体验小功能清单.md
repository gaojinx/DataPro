## 1. 口径说明

### 1.1 什么叫「小功能」

| 维度 | 本次口径 |
|---|---|
| 范围 | 微交互 / 小细节 / 显示层增强；**一两天可落地、用户下一次使用就能感知** |
| 排除 | 需要新增页面、新增后端表、改 9 节点状态机、动权限模型的能力——那些属于「缺口」不属于「小功能」 |
| 证据 | 每条必须给出 `App.vue:行号` 或 `style.css:行号` 证明**当前确实缺**；已实现的即使很像也不列 |
| 红线 | 遵守 `AGENTS.md §4.2-6`：不弹窗、不用常驻小字解释、去渐变/光晕/彩色阴影、字重 ≤600、单一强调色、4px 网格；违反者不进入清单 |

## 3. 优先级矩阵

> 定级口径：**高感知低成本**＝零后端、1~2 天、用户马上看见；**中感知低成本**＝零后端但价值偏锦上添花；**高感知需少量后端**＝需后端补 1 个字段/接口，体验提升明显。
> 架构师评审重点：每张表按行核对依赖与改动面。

### 3.1 高感知低成本（8 条）

| 编号 | 功能名 | 一句话理由 |
|---|---|---|
| X-R01 | 复制整表 TSV | 业务用户每天粘贴到 Excel，零后端、改动仅一个按钮 + 一个剪贴板函数 |
| X-I01 | 草稿自动保存恢复 | 防"打到一半丢失"，纯 localStorage，复用已有持久化模式 |
| X-C01 | 消息级时间戳 | 纯前端 push 时打点即可，回溯价值高（服务端对齐可后置） |
| X-R02 | 表头点击排序 | 本地排序两位数行，省掉用户再问一轮的等待 |
| X-I02 | 示例卡填入可编辑 | 复用卡片 + 现有 input，直接降低第一问拒答 |
| X-A02 | 快捷键 tooltip | 一行 `data-tip`，零新增 UI，完全符合视觉红线 |
| X-L01 | 骨架占位 | 纯 CSS，等待体感立刻变好 |
| X-R03 | 空值占位符 | 显示层一行判断，消除"空白=0"误读，与 KPI 口径统一 |

### 3.2 中感知低成本（7 条）

| 编号 | 功能名 | 一句话理由 |
|---|---|---|
| X-R04 | 表格数值千分位 | 复用 `fmtNum`，但需先确认返回类型避免误格式化编码字段 |
| X-R05 | 结果表行号 | 报障定位有用，价值面窄于排序/复制 |
| X-L02 | 运行中实时耗时 | 已有点阵，加一个 live 计时成本低，但属"知道在跑"的边际改善 |
| X-C02 | 反馈微动效 | 已有颜色状态，补一个回弹即可，价值在反馈率而非功能 |
| X-N01 | 面包屑路径 | 多视图时有用，但当前侧栏高亮已部分承担定位职责 |
| X-I03 | 字符计数 | 取决于后端是否有真实上限，先确认再定形态 |
| X-N02 | 空状态语义图标 | 换图标即可，但属"看起来更对"而非效率提升 |

### 3.3 高感知需少量后端（3 条）

| 编号 | 功能名 | 一句话理由 |
|---|---|---|
| X-L03 | 扫描量预估提示 | 后端 A09 已算 `EXPLAIN` 行数，只需在 SSE 事件补 1 字段；把 E009 从"突然拒绝"变"有预期" |

**为什么是这 10 条：**

1. **覆盖完整高频旅程**：输入（X-I01/X-I02）→ 等待（X-L01/X-L02）→ 看结果（X-R01/X-R02/X-R03）→ 回看与导航（X-C01/X-N01）→ 可发现性（X-A02）。
2. **零后端依赖**：10 条中 9 条纯前端；唯一标注"需少量后端"的 X-C01 也可以先用 `Date.now()` 纯前端降级上线，不阻塞排期。
3. **无视觉红线冲突**：全部复用图标/tooltip/等宽小字/单色徽标，无弹窗、无常驻说明、无渐变光晕、字重不超 600、对齐 4px 网格。
4. **不重复造轮子**：与前两轮 18 条缺口、与 §1.3 已实现细节均无重叠。

## 5. 关键提醒（最易被忽视但体验提升明显）

1. **「结果可复制」看似最小，却是业务用户每天要用的功能。** 当前只能复制答案文本+SQL（`App.vue:1185-1191`）或下载 CSV（`:681-701`），把结果贴进 Excel/微信仍要逐格选——X-R01 的性价比高于再加一种图表。
2. **草稿恢复是"零后端、防丢失"的最高性价比项。** 输入主框无任何持久化（`App.vue:45`），长问句刷新即丢；用户不会为此报障，只会默默少问一次。
3. **空值显示不是美化，是防误读。** 空白单元格容易被当成 0（`App.vue:2477`），但改的时候**绝不能**触碰后端"0 单 ≠ 无数据"的语义（`AGENTS.md §4.2-11`）——只改显示，不动数值、不动脱敏。
4. **视觉红线优先于任何"更像 ChatGPT"的冲动。** 骨架、tooltip、微动效一律去渐变/光晕/彩色阴影、字重 ≤600、单一强调色、4px 网格；反馈用图标/tooltip 而非常驻小字（`AGENTS.md §4.2-6`）。
5. **先核对再动手，别把已实现的当缺口。** Enter/Shift+Enter、Ctrl+K、深色模式、粘性表头、`focus-visible`、回到底部、复制 SQL/答案、重新生成、收藏、追问 chips 均已实现（证据见 §1.3），本次已全部排除。
