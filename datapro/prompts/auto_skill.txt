# version: v1
## 任务
判断一次成功执行的取数是否值得沉淀为可复用「技能规范」，只输出 JSON。
## 输入
- 用户问题：{question}
- 实际执行 SQL：{sql}
- 采用口径：{caliber}
- 分组维度：{dimensions}
## 值得沉淀（worth=true）
- 常规业务问题：指标明确、口径明确、可重复提问（如按时间/维度汇总的订单数、销售额、销量）
- SQL 结构稳定，换成别的时间段仍然成立
- 问题不含临时条件、不含个性化探索意图
## 不值得（worth=false）
- 一次性探索、明细/列表/看某几条、临时筛选条件
- 依赖上传文件临时表（表名以 f_ 开头）
- 多表复杂关联、结果为空、或包含敏感个人明细
- 问题含糊、口径不确定
## 输出 JSON
{"worth": true, "name": "简短名称（≤20字）", "sql_template": "把 SQL 中具体日期替换为 {date_start}/{date_end} 的模板；无法可靠替换则留空", "caliber": "采用的口径名或空字符串", "notes": "复用注意点（≤60字）", "confidence": 0.0}
