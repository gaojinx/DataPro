# version: v1
## 任务
判断本轮对话是否包含值得长期记住的信息，只输出 JSON。
## 输入
- 用户消息：{question}
- 助手回答：{answer}
- 会话类型：{mode}
## 值得记住（remember=true）
- 用户偏好：默认时间范围、粒度、展示方式、常用维度（如“以后默认看最近 7 天”）
- 业务术语或别名：内部叫法、简称（如“我们把支付订单叫有效单”）
- 口径约定：指标按哪个口径统计（如“销售额按支付口径”）
- 使用规则：限制或禁用（如“不要查用户明细”“只看华东区域”）
## 不值得（remember=false）
- 一次性问题、临时条件、闲聊寒暄
- 与数据无关的内容、模型自身信息
- 手机号、身份证、银行卡等任何敏感信息（绝对禁止输出）
## 输出 JSON
{"remember": true, "type": "preference|terminology|rule|caliber", "content": "一句话陈述（≤60字，第三人称）", "confidence": 0.0}
